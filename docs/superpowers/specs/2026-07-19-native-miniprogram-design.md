# 个人作品集原生微信小程序迁移设计

## 目标

将现有 React/Vite 导演作品集迁移为可由微信开发者工具直接打开的原生微信小程序 TypeScript 工程。完整保留首屏、作品、代表样片、导演阐述、关于与联系内容，并尽可能延续现有的浅色、玻璃拟态视觉语言。

## 范围

### 包含

- 新建独立的 `miniprogram/` 原生小程序目录。
- 主页单页纵向浏览体验与锚点式导航。
- 本地作品标签筛选、作品卡片与详情页跳转。
- 作品详情中的视频、基础信息、简介、导演手记、视觉档案与标签。
- 样片区、导演阐述、关于和联系区。
- 图片、视频和作品数据迁移到小程序可用的资源与 TypeScript 数据模块。
- 核心数据和交互逻辑的自动化测试。

### 不包含

- 服务端、投稿、用户账户或内容管理后台。
- Web 版 Framer Motion 动画的逐帧复刻。
- Web 自定义视频播放器的完整移植。
- 自动部署或提交审核。

## 架构

采用「单页作品集 + 作品详情页」结构，保持原网站的一镜到底浏览节奏，同时让内容较长的影片资料在独立页面中展示。

```text
miniprogram/
├── app.json                 # 页面注册、窗口与导航配置
├── app.ts                   # 小程序入口
├── app.wxss                 # 全局色彩、排版和组件样式
├── data/
│   └── works.ts             # 作品数据与筛选逻辑依赖的数据源
├── assets/
│   ├── images/              # 封面、关于页图片与视觉档案
│   └── videos/              # 本地样片与作品视频
├── components/
│   ├── portfolio-nav/       # 顶部锚点导航
│   ├── filter-chips/        # 作品分类筛选
│   ├── work-card/           # 作品卡片
│   ├── section-heading/     # 区块标题和说明
│   └── contact-card/        # 联系信息卡片
├── pages/
│   ├── home/                # 完整纵向作品集主页
│   └── work-detail/         # 单个作品详情页
└── utils/
    ├── works.ts             # 筛选与按 ID 查询
    └── contact.ts           # 联系方式复制行为
```

## 页面与数据流

### 主页

主页按以下顺序渲染：首屏、全部作品、代表样片、导演阐述、关于我、联系我。作品数据从 `data/works.ts` 读取，筛选标签从作品分类和标签派生。点击导航或首屏按钮时，主页调用 `wx.pageScrollTo` 滚动到指定区块；点击作品卡片时跳转到 `work-detail?id=<workId>`。

### 作品详情页

详情页以路由参数 `id` 获取作品。找到作品时展示标题、年份、分类、原生 `video`、基础信息、简介、导演手记、视觉档案和标签。找不到作品时展示明确的空状态与返回主页按钮，避免无效路由导致空白页面。

## 平台适配

- 首屏背景使用静态封面与渐变替代 Web 的全屏背景视频，避免小程序首屏自动播放和性能限制。
- 样片和详情页均使用原生 `<video>` 控件，启用系统提供的进度、音量和全屏能力。
- 联系方式卡片与主按钮调用 `wx.setClipboardData`，复制相应信息并给出成功提示。
- 远程视频地址需配置为小程序合法域名；本地 MP4、封面与图片从 `assets/` 引用。
- 使用 rpx、flex 与 grid 类似的布局方式实现移动优先样式，不依赖 Tailwind、React、Framer Motion 或 Lucide。

## 视觉规范

- 延续现有主色：背景 `#f7f7fb`、文字 `#1B133C`、强调色橙色。
- 以半透明白色卡片、细边框和柔和阴影表达玻璃层次；不使用依赖浏览器 `backdrop-filter` 的关键效果。
- 采用小程序可用的 CSS 过渡和入场淡显，避免复杂滚动动画。

## 验证

- 先为作品筛选、作品 ID 查询、详情页参数解析、联系信息复制及缺失作品状态编写失败测试。
- 每项实现遵循 Red → Green → Refactor：先验证测试因功能缺失而失败，再加入最小实现并运行全量测试。
- 使用 TypeScript 编译检查、单元测试和微信开发者工具预览验证页面注册、资源加载、滚动导航、筛选、详情跳转、视频与复制操作。

## 成功标准

1. 微信开发者工具可直接打开 `miniprogram/` 并识别为原生小程序工程。
2. 首页完整呈现原网站六个内容区块与现有作品信息。
3. 作品可按标签筛选，并能进入对应详情页。
4. 详情页能显示视频和完整作品资料；无效作品 ID 有兜底状态。
5. 联系方式可一键复制。
6. 自动化测试、类型检查和小程序预览均通过。
