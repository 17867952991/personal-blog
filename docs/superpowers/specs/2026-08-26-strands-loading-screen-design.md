# Strands 首屏加载动画设计

**日期：** 2026-08-26  
**状态：** 已确认，待实现

## 目标

为作品集网站的每次页面加载增加全屏加载界面：深色背景上的 React Bits `Strands` 流光动画，搭配 `LOADING······` 文案。加载页停留约 2.5 秒，并在主站内容可显示后平滑淡出。

## 方案比较

1. **纯 CSS 波纹**：依赖最少，但无法复现 Strands 的 WebGL 流光效果。
2. **React Bits Strands（选用）**：通过 `ogl` 渲染彩色光丝，视觉效果与用户提供的组件一致；页面加载期间短暂运行，性能成本可控。
3. **视频/GIF 背景**：效果固定且资源体积较大，不利于首次打开速度。

## 视觉与交互

- 全屏遮罩使用深靛黑背景，位于网站所有内容上方。
- 光丝使用作品集相衬的暖金、紫罗兰、青蓝三色，而非默认彩虹。
- 中央显示大写 `LOADING······`，字距略宽；末尾圆点循环闪烁。
- 页面会至少展示 2.5 秒；若 React 已完成渲染，则在计时结束后淡出；若浏览器尚未触发页面加载完成事件，则继续等待该事件。
- 淡出阶段约 500ms，光丝同步轻微放大和降低透明度，底层主页自然显现。
- 用户设置了“减少动态效果”时，改用静态渐变背景与文字淡出，不初始化 WebGL 动画。

## 组件边界

### `Strands`

- 新增可复用 WebGL 光丝组件，封装 `ogl` 的 Renderer、Program、Mesh、resize 与销毁逻辑。
- 只负责渲染画布，不包含加载状态。

### `LoadingScreen`

- 管理初始可见状态、2.5 秒最短停留时间、`window.load` 事件、淡出和动画清理。
- 对外只提供加载页本身，不影响 `App` 的页面数据、哈希跳转与作品卡片逻辑。

### `App`

- 在现有作品集布局前挂载 `LoadingScreen`。

## 依赖与数据流

- 新增生产依赖：`ogl`。
- 启动时 `LoadingScreen` 启动计时器并监听 `window.load`。
- 计时器和页面加载均满足后，切换为退出状态；过渡结束后从 DOM 卸载。
- `Strands` 卸载时取消 `requestAnimationFrame`、移除 resize 监听并释放 WebGL 上下文。

## 异常处理与性能

- WebGL 初始化异常或浏览器不支持时，加载页继续使用 CSS 渐变背景，保证不阻塞进入主页。
- 画布随容器尺寸更新，且只在加载页的短生命周期内运行。
- 所有定时器与事件监听在卸载时清理，避免 React StrictMode 下遗留动画循环。

## 验证标准

1. 刷新页面会显示约 2.5 秒的全屏 `LOADING······` 动画。
2. 加载完成后平滑显示现有首页；哈希导航和作品弹窗保持正常。
3. 构建与现有测试通过。
4. 部署后在 `https://dwcbumian.github.io/personal-blog/` 验证加载页出现且不会遮住网站内容。
